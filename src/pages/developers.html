The API
Five building blocks.

      
The same objects you see in the dashboard, available as endpoints.

    

    

      
{{icon:send}}/payouts
Payouts
Create payouts to beneficiaries in ten destinations and follow each one to delivery.

      
{{icon:swap}}/swaps
Wallets and swaps
Read balances across six currencies, convert between them and move funds between wallets.

      
{{icon:users}}/beneficiaries
Beneficiaries
Save a recipient’s bank details once, then pay them by ID in any of ten destinations.

      
{{icon:person}}/customers
Customers
Create customer profiles so your platform can send payouts on their behalf.

      
{{icon:bell}}/webhooks
Webhooks
Subscribe to events instead of polling, from wallet funding to delivered payouts.
